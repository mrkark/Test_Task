# Обжарка «Кварта» (Минск) — Лендинг со свежей обжаркой кофе

> **Тестовое задание:** Веб-разработчик Junior+  
> **Стек:** Next.js (App Router, Turbopack), React 19, TypeScript, Tailwind CSS, Zod.

---

## 1. Архитектурные решения

### Хранилище заявок и дедупликация:
1. **Выбор хранилища:** Заявки сохраняются локально в structured JSON (`data/leads.json`) с дублированием в **Telegram-бот** через Telegram Bot API. 
   - *Почему так:* Для тестового задания и быстрого деплоя на бесплатный хостинг (Vercel) локальный файл работает локально, а Telegram-бот выступает в роли мгновенной и отказоустойчивой системы оповещения менеджера без необходимости поднимать платную СУБД. При масштабировании в продакшене код подготовлен к замене файла на **Turso (serverless SQLite)** или **Supabase**.
2. **Дедупликация (10 минут):** Реализована двухуровневая защита:
   - В памяти инстанса поддерживается `Map<phone, timestamp>` с автоматической очисткой старых записей.
   - Проверяется база/файл на наличие заявок с нормализованным номером за последние `10 * 60 * 1000` мс.
   - На клиенте кнопка блокируется от повторного клика (состояние `isSubmitting`).
3. **Белорусский номер:** Написан парсер и валидатор белорусских номеров (`+375`), проверяющий коды операторов (29, 33, 44, 25) и городские линии Минска (17). При вводе телефон автоматически форматируется по маске `+375 (XX) XXX-XX-XX`.
4. **Сквозная аналитика UTM:** Клиентский модуль перехватывает параметры `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, `utm_term` и `referrer`, кэширует их в `sessionStorage` (чтобы метки не терялись при переходах и скролле) и передает в скрытых полях формы при отправке.

## 2. Честный отчёт: Человек vs ИИ

### Что делали сами, а что ИИ:
* **ИИ (LLM):** Помог быстро собрать базовые компоненты интерфейса, сгенерировать типы TypeScript, написать валидацию Zod и бойлерплейт для Telegram API.
* **Человек (Архитектура & Арт-дирекшн):**
  - Сформулировал жесткие негативные ограничения дизайна (*anti-AI look*): полный запрет градиентов, `backdrop-blur`, `shadow-xl` и скруглений `rounded-2xl`.
  - Задал цветовую систему на базе сложных, нечистых крафтовых оттенков (`#F6F4EE`, `#1C1917`, `#B84A28`) и добавил тактильную SVG-шум текстуру в CSS.
  - Спроектировал асимметричную журнальную композицию Hero-секции и таймлайн обжарки вместо шаблонной сетки из 3 карточек.
  - Продумал механику авто-подстановки выбранного сорта из каталога прямо в селектор формы.

### Где ИИ ошибся и как это заметили:
1. **Регулярка для телефонов:** ИИ изначально предложил шаблонный regex `^\+375\d{9}$`, который пропускал несуществующие коды регионов (например, `+375 11 ...` или `+375 99 ...`). Ошибка была замечена при составлении тест-кейсов и исправлена строгой валидацией по кодам операторов Беларуси `(29|33|44|25|17)`.
2. **Шаблонный «ИИ-дизайн»:** На первых итерациях модель пыталась навязать фиолетово-синие градиенты, полупрозрачные стеклянные карточки и центрированный Hero. Потребовался жесткий промптинг с Negative Constraints для получения чистой студийной журнальной эстетики.
3. **Конфликт типов модулей в package.json:** `npm init -y` создал `"type": "commonjs"`, из-за чего сборщик Next.js выдавал ошибку несоответствия ESM. Это было выявлено на этапе тестовой компиляции и устранено.
4. **Edge runtime в opengraph-image:** ИИ сгенерировал устаревший флаг `runtime = "edge"`, выдавший ворнинг в Next.js 16. Заменено на поддерживаемый `runtime = "nodejs"`.

### Что не успели или сделали бы иначе:
* В продакшене подключили бы **Turso (LibSQL)** с миграциями через Drizzle ORM, чтобы заявки никогда не терялись при cold-restart в Vercel Serverless.
* Добавили бы интерактивный калькулятор чашек: бегунок «Сколько чашек вы пьете в день», рассчитывающий расход зерна в месяц для подписки.

## 3. Запуск проекта

### Требования:
- Node.js 18+ (протестировано на Node.js 24)
- npm 9+

### Установка и локальный запуск:
```bash
# 1. Установка зависимостей
npm install

# 2. Создание файла окружения (опционально для Telegram)
cp .env.example .env.local

# 3. Запуск dev-сервера
npm run dev
```
Откройте [http://localhost:3000](http://localhost:3000) в браузере.

### Запуск тестов валидации и дедупликации:
```bash
npx tsx scripts/test-leads.mjs
```

### Сборка продакшн-билда:
```bash
npm run build
npm run start
```
