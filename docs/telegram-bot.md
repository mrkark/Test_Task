# Бот «Кварты»

Присылает заявки с сайта и показывает статистику: сколько заявок и когда.

| Команда | Что делает |
|---|---|
| `/start` | включает уведомления (в первый раз — приветствие) |
| `/stop` | пауза: заявки сохраняются, в чат не приходят |
| `/restart` | начать заново: уведомления включены, период статистики снова «7 дней» |
| `/stats` | заявки за 7 дней / 4 недели / всё время; кнопки переключают период |

Статистика: всего, среднее в день, сегодня и вчера, самый сильный день, столбики по дням (неделям, месяцам), что выбирали, пять последних заявок. Дни считаются по Минску. Имён и телефонов в статистике нет.

## Подключение

1. В @BotFather: `/newbot`, взять токен.
2. Написать боту любое сообщение и узнать номер своего чата (чужой чат бот сам назовёт в ответе на `/start`).
3. Переменные на Vercel: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` (чаты команды через запятую), `TELEGRAM_WEBHOOK_SECRET` (любая длинная случайная строка).
4. После деплоя: `node --env-file=.env.local scripts/telegram-setup.mjs https://ваш-домен`.

Доступ только у чатов из `TELEGRAM_CHAT_ID` и `TELEGRAM_ALLOWED_CHAT_IDS`: бот видит телефоны клиентов. Вебхук без секрета отвечает 503.
Локально без публичного адреса: `npm run bot:poll` (long polling, вебхук при этом нужно снять).
